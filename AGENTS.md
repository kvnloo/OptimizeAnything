# OptimizeAnything agent contract

Optimize application outcomes, not language count. Start with an unchanged
baseline and a frozen outcome contract. A same-language optimization is a valid
product candidate. Translation-only benchmarks have a separate no-substitution
rule. Preserve author credit, licenses, provenance, and failed experiments.

Use branches; never merge the default branch. Do not publish target upstream
changes, spend on APIs, or start recurring jobs without authorization.

For the first experiment, read README.md and targets/leven/CONTRACT.md. Do not
change the reference, corpus, contract, integrity pins, or acceptance criteria
to make a candidate pass. Run the Python tests and the full differential check.
Missing tools => BLOCKED. Wrong results => FAIL. Public corpus success =>
PILOT_PASS, not independent verification or a production optimization claim.

The included Rust candidate is a seeded port; do not expose it to a fresh
one-shot benchmark agent. Keep independent grading outside its writable mount.
Do not claim this process supervisor is a sandbox. No unsafe Rust, substitute
edit-distance crate, or delegation back to JavaScript in the translation track.

Factory integration is optional. Before factory automation uses this project,
register it in kvnloo/oss-factory/factory/projects.json through review; do not
create a competing global registry here. This first implementation does not
activate factory automation or any external optimization backend.
